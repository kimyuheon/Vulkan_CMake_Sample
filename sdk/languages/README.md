# UI 언어 파일 편집 방법

`languages` 폴더의 `.lang` 파일은 우측 상단 언어 선택기에 자동으로 나타납니다.

1. `en.lang`을 복사해 `ja.lang`처럼 새 이름으로 저장합니다.
2. `@code`에는 겹치지 않는 짧은 코드, `@name`에는 선택기에 표시할 이름을 적습니다.
3. `=` 오른쪽 문장만 번역합니다. `=` 왼쪽 키는 바꾸지 않습니다.
4. 앱의 언어 선택기에서 **번역 파일 다시 읽기**를 누릅니다.

빈 줄과 `#` 또는 `;`로 시작하는 줄은 무시됩니다. 줄바꿈은 `\n`, 탭은 `\t`로
적습니다. 번역 키가 빠져도 해당 컨트롤이 사라지지 않고 기본 한국어 문장으로 표시됩니다.

```text
@code=ja
@name=日本語 (JP)

menu.file=ファイル
menu.edit=編集
```
